Docsio builds your entire documentation site through a five-phase AI process. Understanding each phase helps you get the best results.

## Phase 1: Brand extraction

The AI agent's first step is extracting your brand identity from your website. It reads your CSS, analyzes your design, and downloads your assets.

**What gets extracted:**
- Primary and secondary colors from your website's color palette
- Logo and favicon, downloaded automatically
- Typography (body font and heading font)
- Light or dark theme preference based on your site's design

All extracted brand elements are applied to your documentation site automatically. Your docs look and feel like your product from the very first preview. No manual color picking, no design work required.

:::note
If you're uploading documents instead of pasting a URL, you can manually set your brand colors and upload a logo in the editor after generation.
:::

## Phase 2: Analysis

The AI agent maps your entire website and scrapes your content. It identifies which pages contain product information, features, integrations, and configuration details.

**What happens:**
- Your full website is mapped (typically 20-100+ pages)
- Product pages, feature pages, and documentation are identified
- Marketing pages and legal content are filtered out
- Content is organized by topic and relevance

The AI only uses real information found on your website. It never fabricates features, invents API endpoints, or makes up content. If information isn't on your site, it won't appear in your docs.

## Phase 3: Building

The AI writes every documentation page using the content it scraped. It structures pages following the Diataxis framework, which organizes documentation into four types: tutorials, how-to guides, explanations, and reference material.

**What gets created:**
- Getting started guide with installation or setup steps
- Feature documentation pages explaining each major capability
- Integration guides for connected services
- API reference pages (if your product exposes an API)
- Homepage with real features and product overview
- Navigation structure and sidebar organization
- Footer with working links

Each page is written from scratch using only real information from your website. The AI ensures every page has proper headings, code examples, and clear explanations.

:::tip
The AI writes pages in Markdown format. You can edit any page manually after generation if you want to refine the wording or add custom content.
:::

## Phase 4: Polishing

The AI agent reviews the generated site for quality and consistency. It checks for:

- Broken links or missing references
- Incomplete pages or missing sections
- Inconsistent formatting or structure
- Navigation issues or missing sidebar items
- Brand color application across all pages

Any issues found are fixed automatically. The result is a polished, complete documentation site ready for publication.

## Phase 5: Audit

Before you see the site, the AI runs a final audit to ensure everything is correct. It verifies:

- Every internal link points to a real page
- Every code block is properly formatted
- Every page has a clear title and description
- Navigation is complete and consistent
- Brand colors are applied throughout
- Mobile responsiveness is correct

Only after passing the audit does the site appear in your live preview.

## Real-time progress

You watch the entire five-phase process happen in real time. Each step appears as a live status update so you always know what the AI is doing. This transparency lets you understand exactly how your documentation site is being built.

```
Extracted brand: #1a1a2e, logo, 2 fonts
Mapped 32 pages on acme.com
Batch scraped 18 product pages
Created 14 documentation pages
Built homepage with real content
Writing footer with navigation links...
Audit: Checking all links
Audit: Verifying page structure
Audit: Checking mobile responsiveness
Done. Site is ready to preview.
```

## After generation

Once the AI finishes building your site, you can:

1. **Preview**, Navigate the live preview to see exactly what will be published.
2. **Edit**, Chat with the AI agent to make any changes. Describe what you want and it updates the site in real time.
3. **Publish**, Press Publish and your docs go live with automatic SSL in seconds.

The AI agent stays with you as an editor. You can make unlimited changes to colors, content, pages, navigation, and more. Every change appears in the live preview instantly.

:::warning
The free plan includes 20 AI agent edits per month. Each edit (changing a color, adding a page, rewriting content) counts as one edit. If you need unlimited edits, upgrade to Pro.
:::
