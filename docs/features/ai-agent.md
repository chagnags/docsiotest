The AI editing agent stays with you after your documentation site is generated. Chat with it to make any change you want: colors, pages, content, navigation, CSS, or layout. No code required.

## What the agent can do

The AI agent has full read and write access to every file in your documentation project. This means it can:

- **Edit content**, Rewrite pages, add sections, update examples
- **Change colors and fonts**, Modify your brand colors, typography, and theme
- **Add or delete pages**, Create new documentation pages or remove old ones
- **Reorganize navigation**, Update sidebar structure and categories
- **Modify CSS**, Change layouts, spacing, responsive design
- **Upload images and documents**, Add screenshots, diagrams, PDFs, and other media
- **Update configuration**, Change site title, tagline, navbar links, footer content

Anything you can describe in plain English, the agent can build.

## How to use it

1. Open the editor and click **Ask the agent** at the bottom.
2. Describe what you want to change in plain English.
3. Watch the agent work in real time as it reads files, makes changes, and updates the preview.
4. The live preview updates instantly so you see the result immediately.

You don't need to know how the site is built or what files to edit. Just describe what you want and the agent handles the implementation.

## Real-time progress

As the agent works, you see each step happen in real time:

```
Working...
Reading custom.css
Updated navbar colors
Added dark mode toggle
Done. Navbar and links now use your brand color. 
Dark mode toggle added to the top right. Preview is live.
```

This transparency lets you understand exactly what the agent is doing and verify that the changes are correct.

## Example changes

**Change the primary color:**
> "Change the primary color to teal and update all links to match"

The agent reads your CSS, updates the color variables, and applies them throughout light and dark mode.

**Add a new page:**
> "Create a new page called 'Troubleshooting' with common issues and solutions"

The agent creates the page, adds it to the sidebar, and updates navigation.

**Embed a video:**
> "Add a demo video to the Quick Start page"

The agent reads the Quick Start page, adds a responsive video embed, and updates the surrounding text.

**Reorganize the sidebar:**
> "Move the API Reference section to the top and rename it to 'API Docs'"

The agent updates the sidebar structure and navigation.

## Natural language editing

You don't need to know the technical details of how your site is built. The agent understands:

- Feature names and product terminology
- Design concepts like "primary color", "sidebar", "navbar"
- Common tasks like "add a page", "change the font", "embed a video"
- File operations like "create", "delete", "rename"

Just describe what you want in plain English and the agent figures out the implementation.

:::tip
Be specific about what you want. Instead of "make it better", try "change the heading color to match the primary brand color and increase the font size by 2px".
:::

## Edit limits

The free plan includes 20 AI agent edits per month. Each change (rewriting a page, changing a color, adding a new page) counts as one edit.

If you need unlimited edits, upgrade to Pro for $60/month per site.

:::note
You can also edit pages manually in the editor without using the AI agent. Manual edits don't count against your edit limit.
:::
